# Описание

проект обновления промпта на задаче извлечения признаков из документов. Маленькая модель извлекает данные из документов, большая модель смотрит на ошибки и улучшает промпт.

# Подготовка

создать и заполнить файл `.env` из примера `.env.example`. Переменные:

- OPENAI_BASE_URL - базовый URL до провайдера моделей
- OPENAI_API_KEY - ключ доступа к провайдеру
- OPENAI_REFINE_MODEL - имя большой модели для улучшения промпта
- OPENAI_GENERATION_MODEL - имя маленькой модели для извлечения сущностей

Остальные параметры в разделе `Подготовка Langfuse`

## Установка зависимостей

```
uv sync
```

## Подготовка Langfuse

Данные, промпты, оценки точности хранятся в Langfuse. Чтобы его запустить локально, следуйте инструкциям https://langfuse.com/self-hosting/deployment/docker-compose  
Далее в UI нужно создать организацию и в ней проект. Слева снизу зайти в настройки проекта, перейти в раздел API Keys. Создать ключ и скопировать переменные среды в файл `.env`.

## Подготовка данных

В проекте используется датасет https://huggingface.co/datasets/irlspbru/RusLawOD  
В терминале, находясь в корневой папке проекта выполнить:

```
python -m src.data.load_dataset
```

Датасет скачается в папку `data/raw`.  
Далее датасет нужно сохранить в Langfuse, для этого выполняем команду:

```
python -m src.data.fill_langfuse
```

# Запуск проекта

Выполнить команду

```
python main.py
```

Агент запустится и выполнит несколько итераций улучшения промпта.  
Доступны различные параметры для переопределения, чтобы их увидеть выполните команду:

```
python main.py --help
```
